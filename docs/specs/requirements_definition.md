## 5. 機能要件
### 5.1 機能一覧
| No   | 機能名     | 概要                     | 優先度 |
| ---- | ---------- | ------------------------ | ------ |
| F-01 | ユーザ登録 | ユーザ情報を登録する機能 | 低     |
| F-02 | ログイン   | 認証機能                 | 低     |
| F-03 | 相関図管理   | 相関図のCRUD処理                 | 高     |
| F-04 | エンティティ管理   | エンティティのCRUD処理                 | 低     |
| F-05 | エンティティ管理   | エンティティのマスタ                 | 低     |
| F-06 | 相関図出力   | 相関図の共有                 | 低     |
| F-07 | 相関図の表示切替   | 複数の表示が可能                 | 低     |

### 5.2 詳細機能仕様
**例：F-01 ユーザ登録**
- **入力項目**：氏名、メール、パスワード
- **処理内容**：入力データを検証後、DBに登録
- **出力**：登録完了メッセージ、ユーザID

**F-03 相関図管理**
- **入力項目**
  - 相関図名
  - 相関図詳細
  - エンティティ名
  - エンティティ種別
  - エンティティ詳細
    - 生年月日
    - 性別
- **処理内容**
  - 家系図として表示する
- **出力**
  - グラフ
  - トグルイントグル
  - 箇条書き
