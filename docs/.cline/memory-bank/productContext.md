## プロダクトが存在する理由

- 家系図を表現するための適切な方法がないため

## 解決する問題

- 家系図の視覚的理解
- 家系図の経時的な更新
- 創作における相関図整理
- 相関図の共有

## どのように機能すべきか

- 相関図を作成・更新・削除できること
- 各人物を登録できること

## ユーザー体験の目標

- 関係性を容易に理解できること
- 続柄における類似関係を把握できること
- 人に限らず動植物を登録できること
